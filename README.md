# Spelling Bee Vocabulary

เว็บแอปฝึกสะกดคำภาษาอังกฤษจากเสียงอ่าน (Text-to-Speech) พร้อมแปลคำศัพท์เป็นไทยและเก็บประวัติคำตอบย้อนหลัง

## Features

- ฝึกสะกดคำจากเสียงอ่านแบบสุ่ม
- เลือกสำเนียง/ภาษาในการออกเสียงได้หลายภาษา
- ปรับความเร็วเสียงอ่านได้
- แสดงผลว่าตอบถูกหรือผิด พร้อมคำแปล
- เก็บ log คำตอบย้อนหลังในหน้าเดียว พร้อมปุ่มล้างประวัติ
- แสดงสถิติแบบเรียลไทม์ (streak, accuracy, best streak)
- รองรับ Dark Mode และจำค่าการตั้งค่าเดิมด้วย `localStorage`
- รองรับการใช้งานบนมือถือ/แท็บเล็ต/เดสก์ท็อป (responsive)

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript
- Web Speech API (`speechSynthesis`)

## Getting Started

1. Clone repository
2. เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์สมัยใหม่ (แนะนำ Chrome/Edge)
3. กดปุ่ม **เริ่มเกม!** เพื่อเริ่มฝึก
